EXPORTAÇÕES — XLSX direto no navegador + MPP via Helper Local

XLSX:
- O navegador gera os arquivos .xlsx diretamente usando SheetJS.
- EAP-Base (.xlsx): estrutura com níveis, EDT e predecessoras.
- Lista de Documentos (.xlsx): abas "Informações do Projeto" e "LD", prontas para controle.
- Exportar tudo (.xlsx): EAP-Base e Cronograma no mesmo arquivo.

MPP:
- O navegador envia os dados para um helper local em Python/Windows.
- O helper usa Microsoft Project + COM (pywin32) para criar o .mpp nativo.
- Requer: Windows + MS Project instalado + helper rodando localmente.

Fluxo:
1) Gere a EAP / cronograma no HTML.
2) Clique em “Verificar Helper Local”.
3) Se ficar ONLINE, use os botões .MPP.
4) Para .XLSX, não precisa do helper.
5) Para .MPP, o helper agora valida a geração e só confirma sucesso quando o download do arquivo realmente ocorrer.

Como iniciar o helper (Windows):
- Abra a pasta "helper" e dê dois cliques em INICIAR_HELPER_MPP.bat
  (instala o pywin32 na primeira vez e sobe o servidor local).
- Em caso de erro, rode DIAGNOSTICO_HELPER.bat.

Porta padrão do helper: http://127.0.0.1:8765

O navegador não cria .mpp sozinho. O .mpp é gerado por um helper local em Python/Windows que automatiza o Microsoft Project. Já o .xlsx sai direto do próprio HTML.

Etapa 1 · Documentação de referência

Análise de documentação → EAP (PMBOK)

Proposta técnica, contrato, termo de referência ou edital. O sistema extrai o escopo e monta uma EAP orientada a entregas, com gerenciamento, marcos, durações, predecessoras e dicionário — pronta para o MS Project.

1. Análise automática (offline)

Identifica seções de escopo, entregáveis, prazos, premissas, exclusões e critérios de aceitação por regras. Nada sai do seu computador.

2. Análise com IA (opcional)

Mais precisa em documentos longos ou pouco estruturados. Usa a sua chave de API da Anthropic. O texto dos documentos é enviado à API. Verifique se a confidencialidade do contrato permite.

Sem chave? Use o modo manual: copie o prompt, cole no Claude e importe o JSON da resposta.

Exportar

MS Project (.xml) não precisa de instalação: no MS Project use Arquivo › Abrir, escolha o tipo Formato XML e selecione o arquivo. A EAP, os marcos, as durações, as predecessoras e o dicionário (em Anotações) são importados; depois é só Salvar como .mpp. O botão .mpp via helper gera o arquivo nativo direto, mas exige o helper local rodando (aba Exportações).
